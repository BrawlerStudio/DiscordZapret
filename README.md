> [!WARNING]
>
> ### О срабатываниях антивирусов
>
> Для работы zapret нужен WinDivert — инструмент перехвата и фильтрации сетевого трафика. Антивирус может отреагировать на него, поскольку такой инструмент способен применяться как полезными, так и вредоносными программами, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы считают файлы WinDivert потенциально опасными или относят их к хакерским инструментам. В результате файл удаляется и попадает в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы понимаете, как правильно настроить исключения, используйте их; в противном случае рекомендуется отключить обнаружение PUA.

## ⚙️Установка и использование

1. Включите безопасный DNS (Secure DNS).
    * В Chrome активируйте "Использовать безопасный DNS" и укажите поставщика, не выбирая вариант "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS в настройках системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется.
    * На роутерах Keenetic включите параметр "Транзит запросов". При его отключении Secure DNS на компьютере может работать неправильно.

2. Скачайте zip- или rar-архив со [страницы последнего релиза](https://github.com/BrawlerStudio/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и установите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не требуется.

4. Распакуйте файлы в каталог, в пути к которому нет кириллицы и специальных символов.

5. Запустите нужный скрипт:
    * Для поиска рабочей стратегии откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
    * Для добавления стратегии в автозапуск выберите **`service.bat`** → `Install Service` → нужную стратегию.

## ℹ️Что делают файлы

- [**`general.bat ...`**](./general.bat) — запускает стратегию вручную.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты, включая ALT, FAKE и другие, пока не найдёте подходящий**.

- [**`service.bat`**](./service.bat) — управление автозапуском и дополнительные операции:
  - <ins>**`Install Service`** — добавляет выбранную стратегию в автозапуск Windows (`services.msc`).</ins>
  - **`Remove Services`** — удаляет стратегию и WinDivert из служб.
  - **`Check Status`** — показывает состояние обхода и служб, включая стратегию автозапуска и WinDivert.
  - **`Game Filter`** — переключает обход для игр и прочих сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения настройки стратегию необходимо перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** — меняет режим обхода сервисов из `ipset-all.txt`.  
  Это может пригодиться при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках указано состояние:
    - `none` — ни один IP не проверяется;
    - `loaded` — IP проверяются на наличие в списке;
    - `any` — под фильтр попадает любой IP.
  - **`Auto-Update Check`** — включает или отключает автоматическую проверку обновлений.
  - **`Replace active fakes`** — заменяет используемый fake другим файлом из каталога `bin`.
  - **`Update IPSet List`** — загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновляет hosts <ins>**для исправления веб-версии Telegram и подключения к голосовому чату Discord**.</ins>
  - **`Check for Updates`** — вручную проверяет наличие новой версии.
  - **`Run Diagnostics`** — ищет распространённые причины неисправности zapret.  
  В финале доступна очистка кэша <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного прекращения работы.
  - **`Run Tests`** — запускает проверку стратегий:
    - `Standard tests` — проверяет сайты из `utils/targets.txt`;
    - `DPI checkers` — проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не видно

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться `winws.exe` — процесс обхода, видимый на панели задач.  
Если этого не произошло, обратитесь к [#522](https://github.com/BrawlerStudio/zapret-discord-youtube/issues/522).

### Ни одна стратегия не работает

- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере

Откройте **`service.bat`** и выполните **`Update hosts file`**. Если используемый hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - В появившейся папке откройте файл `hosts` текстовым редактором, запущенным от имени администратора.
  - Вставьте скопированное в конец `hosts` или замените ранее добавленные аналогичные строки.
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа не гарантируется. Если способ не помог, используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/BrawlerStudio/tg-ws-proxy) или любым публичным прокси.

### Обход перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Обнаружение определённой стратегии может произойти не сразу: некоторое время она работает, а затем перестаёт. В репозитории есть много вариантов обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из существующих и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте ошибки через `service.bat` → `Run Diagnostics`.
- Удостоверьтесь, что адрес нужного ресурса присутствует в списках доменов или IP.
- Проверьте другие варианты, в том числе **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация есть в [#765](https://github.com/BrawlerStudio/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление

- Сохраните ресурсы и данные, которые добавляли самостоятельно.
- Перезапустите устройство.
- В `service.bat` выберите `Remove Services`.
- Запустите `service.bat` → `Run Diagnostics`; исправьте найденные ошибки и в конце ответьте `Y`.
- Удалите текущий каталог zapret.
- Загрузите свежую версию [со страницы релизов](https://github.com/BrawlerStudio/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть флажок разблокировки, установите его, нажмите «Применить», затем «ОК».
- Распакуйте архив в новый каталог в корне диска, без пробелов и специальных символов.
- Запускайте разные `general`-скрипты и проверяйте доступность ресурсов. Если вариант не работает, закройте программу через значок замка на панели задач и попробуйте следующий.
- После выбора рабочей стратегии добавьте её в автозапуск: `service.bat` → `Install Service` → нужная стратегия.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе обход может повлиять на доступ к неожиданным для вас ресурсам.

### Античит обнаруживает WinDivert

- Инструкция находится [здесь](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть в службах

1. Узнайте имя службы в командной строке Windows (`Win+R`, затем `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Попробуйте остальные стратегии, особенно если раньше всё работало.
- См. также [#251](https://github.com/BrawlerStudio/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ею.
- Если Discord не открывается и в браузере, повторно проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/BrawlerStudio/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/BrawlerStudio/tg-ws-proxy).
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Универсальная последовательность действий:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учтите: режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Вместо этого определите все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.

Если проблема сохранится, создайте обсуждение в разделе [Discussions](https://github.com/BrawlerStudio/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли подходящего ответа

- Опишите проблему [здесь](https://github.com/BrawlerStudio/zapret-discord-youtube/issues).

## 🗒️Добавление адресов других ресурсов

Списки обхода можно дополнить следующими файлами:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены-исключения, например когда IP-сеть уже есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — исключения для IP-адресов и подсетей.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
